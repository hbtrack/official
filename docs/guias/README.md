# docs/guias

`docs/guias/` é material humano de estudo, ideação e exploração.

Regras:
- não é canon;
- não é SSOT;
- não define status operacional, DONE ou próxima ação permitida;
- não substitui `docs/_canon/`, `docs/hbtrack/modulos/` ou `ROADMAP.md`.

Se algum guia usar linguagem de autoridade, ele deve trazer disclaimer explícito no topo.
