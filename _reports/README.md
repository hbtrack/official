# _reports

`_reports/` contém artefatos derivados, evidências, snapshots e relatórios gerados pelo pipeline.

Regras:
- não é canon;
- não é SSOT;
- não define escopo, status soberano ou próxima ação permitida;
- serve como evidência e observabilidade do processo.

Em conflito com fontes soberanas, prevalecem `docs/_canon/`, `docs/hbtrack/modulos/`, `contracts/` e `.contract_driven/`.
